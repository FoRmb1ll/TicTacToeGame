# Крестики-нолики

## О проекте
Консольная игра "Крестики-нолики" на C# с двумя версиями функционала.

## Автор
- **ФИО:** Дедюхин Дмитрий Артемович
- **Группа:** ИСП(9)-23-1
- **Дата начала:** 28.02.2026

## Версии игры

### Версия 1.0
- Классическая игра в крестики-нолики
- Два игрока по очереди ставят X и O
- Проверка победы и ничьей

### Версия 2.0
- Счетчик побед для каждого игрока
- Сохранение статистики между запусками
- Кастомизация символов игроков
- Удобное меню и интерфейс

## Технологии
- C# (.NET 6.0/8.0)
- Visual Studio 2022
- Git / GitHub
